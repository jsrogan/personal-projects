## Python Tkinter Calculator

My take on a classic CS self paced project, I took the bulk of the code from this [guide]([url](https://www.geeksforgeeks.org/python/python-simple-gui-calculator-using-tkinter/)) and added a mod operation (checking what the remainder is after division) and allowed for continuous operations.

Continuous operations can be defined as storing the result of a prior calculation (say 4*4=16), and using that result as the base of the next operation if the user presses an operator button (+, -, /, *, %), otherwise resetting the expression to whatever the user presses.
